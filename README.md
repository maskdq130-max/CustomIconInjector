# 🎨 CustomIconInjector

Твик для iOS, предназначенный для динамической подмены иконок приложений на уровне системы (SpringBoard).

## 📌 Описание
Проект перехватывает метод отрисовки иконок в SpringBoard и подменяет стандартные изображения на кастомные из локальной директории устройства.

## 🛠️ Структура и настройка
После установки твика размещайте кастомные иконки в формате `.png` по следующему пути на устройстве:
`/var/mobile/Library/Themes/CustomIcons/<BundleID>.png`

**Примеры именования файлов:**
- `com.apple.Preferences.png` — для приложения «Настройки»
- `ph.telegra.Telegraph.png` — для Telegram

## ⚙️ Сборка
Сборка осуществляется автоматически при каждом push-событии в ветку `main` с помощью **GitHub Actions** (используется фреймворк Theos). Готовый `.deb` пакет можно скачать из раздела **Actions** -> **Artifacts**.
